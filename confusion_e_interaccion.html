Confusión e Interacción en Regresión

Análisis de variables confusoras y efectos de interacción en R

¿Qué es la Confusión?

La confusión ocurre cuando una tercera variable (variable confusora) afecta tanto a la variable independiente como a la dependiente, sesgando la relación observada entre ellas.

¿Qué es la Interacción?

La interacción existe cuando el efecto de una variable independiente sobre la variable dependiente depende del nivel de otra variable independiente.

Diferencias Clave

Confusión: Sesga el efecto (relación aparente)
Interacción: Modifica el efecto (relación real que varía)

Detectar Confusión en R


# Modelo sin variable confusora
model1 <- lm(y ~ x, data = df)

# Modelo con variable confusora
model2 <- lm(y ~ x + z, data = df)

# Comparar coeficientes de x
coef(model1)[2]
coef(model2)[2]

Detectar Interacción en R


# Modelo con interacción
model3 <- lm(y ~ x + z + x:z, data = df)

# O utilizando el operador *
model3 <- lm(y ~ x * z, data = df)

# Ver el coeficiente de interacción
summary(model3)

Visualización de Confusión

Usa gráficos de dispersión para mostrar la relación entre x e y, estratificada por la variable confusora z.


ggplot(df, aes(x = x, y = y, 
               color = factor(z))) +
  geom_point() + 
  geom_smooth(method = "lm", se = FALSE)

Visualización de Interacción

Los gráficos de interacción muestran líneas de regresión no paralelas cuando el efecto de x sobre y cambia según z.

Prueba Estadística de Interacción


# p-valor del término de interacción
summary(model_with_interaction)

# Si p < 0.05, hay evidencia de interacción

📌 Notas Importantes

Confusión es un problema metodológico que puede controlarse en el análisis. Interacción es una pregunta de investigación legítima sobre cómo los efectos varían según el contexto.

Cuando hay interacción, el efecto principal no es constante y debe interpretarse condicionado al nivel de la otra variable.
